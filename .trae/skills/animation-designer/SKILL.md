# Animation Designer Skill

Professional toolkit for implementing high-quality animations and motion design in web applications.

## Features
- CSS animation and transition optimization
- JavaScript-based motion design with popular libraries
- Performance profiling for animations
- Scroll-triggered animations implementation
- Micro-interactions design patterns
- Loading states and skeleton animations
- Page transition and route animations
- 3D transforms and perspective effects
- Animation performance best practices
- Reduced motion accessibility support

## When to use
- When implementing complex CSS animations and transitions
- When adding scroll-based animations to pages
- When designing micro-interactions for UI components
- When creating loading states and skeleton screens
- When implementing smooth page transitions
- When adding 3D effects and transforms
- When optimizing existing animations for performance
- When ensuring animations respect reduced-motion preferences
