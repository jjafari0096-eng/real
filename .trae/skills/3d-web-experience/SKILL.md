# 3D Web Experience Skill

Professional toolkit for building immersive, performant 3D experiences on the web using modern WebGL technologies and libraries.

## Features
- Three.js scene setup and optimization
- WebGL rendering performance tuning
- Interactive 3D model implementation
- GLTF/GLB model loading and optimization
- Real-time lighting and material systems
- Camera controls and orbit navigation
- 3D particle systems and visual effects
- React Three Fiber integration for React projects
- @react-three/drei and @react-three/cannon usage
- WebXR and virtual reality support
- 3D model compression and LOD implementation
- Mobile 3D performance optimization
- Cross-browser 3D compatibility

## When to use
- When implementing 3D product visualizations (like property tours for real estate)
- When creating interactive 3D scenes with Three.js
- When integrating React Three Fiber in React applications
- When optimizing 3D models for web delivery
- When adding virtual tour capabilities to websites
- When implementing WebXR experiences
- When creating 3D particle effects and animations
- When building physics-based 3D interactions
- When troubleshooting 3D rendering performance issues
- When implementing cross-platform 3D experiences
