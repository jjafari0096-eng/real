# Framer Motion Animator Skill

Professional toolkit for creating powerful animations and interactions using the Framer Motion library in React applications.

## Features
- React component animation with motion components
- Gesture recognition (drag, hover, tap, pan)
- Scroll-linked animations and viewport triggers
- Layout animations and shared layout transitions
- Animation orchestration with AnimatePresence
- SVG path and shape animations
- 3D transforms and physics-based animations
- Performance optimization for Framer Motion
- TypeScript integration best practices
- Server-side rendering compatibility

## When to use
- When implementing animations in React with Framer Motion
- When adding drag-and-drop interactions
- When creating scroll-triggered animations
- When implementing shared element transitions
- When working with AnimatePresence for mounting/unmounting animations
- When animating SVG graphics and charts
- When adding physics-based motion effects
- When optimizing Framer Motion animations for production
- When integrating Framer Motion with TypeScript
